# Alberto.dev | Portfolio personal

Portfolio web de Alberto Ávila Orero, estudiante de Desarrollo de Aplicaciones Web (DAW) y técnico en Sistemas Microinformáticos y Redes.

El proyecto reúne mi formación, experiencia, conocimientos técnicos y proyectos personales en una interfaz interactiva inspirada en los paneles de control de aplicaciones modernas.

## Tecnologías

![HTML, CSS y JavaScript](https://skillicons.dev/icons?i=html,css,js)

- HTML5: estructura y contenido.
- CSS3: diseño Bento Grid, Flexbox y adaptación responsive.
- JavaScript: interactividad, eventos y manipulación del DOM.
- LocalStorage: almacenamiento de la preferencia de tema.

## Funcionalidades

- Diseño adaptable a móviles y ordenadores.
- Terminal interactiva con comandos, historial y autocompletado.
- Modo claro y oscuro.
- Filtrado de proyectos por categoría.
- Acceso al currículum y a mis perfiles profesionales.

## Ejecución local

```bash
git clone https://github.com/Alberto-Avila-Orero/Portfolio.git
cd Portfolio
```

Abre `index.html` en el navegador o utiliza Live Server en Visual Studio Code. No es necesario instalar dependencias.
